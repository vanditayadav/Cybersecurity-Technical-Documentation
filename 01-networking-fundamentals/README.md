# 01 — Networking Fundamentals

## Overview

This section documents my foundational networking studies, technical concepts, practical exercises and understanding of network communication and infrastructure.

My networking learning followed a structured, phased approach using learning resources from Professor Messer and Jeremy's IT Lab.

The curriculum progressed from core networking principles to traffic and services, switching, monitoring, security-relevant networking and introductory modern networking concepts.

The objective was to establish a strong networking foundation relevant to cybersecurity, SOC operations, network traffic analysis and digital investigations.

## Learning Structure

### Phase 1 — Absolute Core

**Learning objective:** Develop a strong understanding of fundamental networking concepts.

Topics:
- Network functions
- Introduction to IP
- Network communication
- Common ports
- IPv4 addressing
- IPv4 subnet masks
- Calculating IPv4 subnets and hosts
- Network devices
- Interfaces and cables
- Connecting network devices
- How TCP/IP works
- Ethernet LAN switching
- IPv4 headers
- Routing fundamentals
- TCP and UDP
- Life of a packet

### Phase 2 — Traffic and Services

**Learning objective:** Understand how network services operate and how traffic moves across networks.

Topics:
- DHCP
- DHCP configuration
- DNS overview
- DNS records
- Network Address Translation (NAT)
- Static NAT
- Wireshark demonstration

### Phase 3 — Switching and Segmentation

**Learning objective:** Understand network segmentation and the purpose of switching-related security and reliability mechanisms.

Topics:
- VLANs and trunking
- Interface configurations
- Spanning Tree Protocol (STP)
- STP analysis
- PortFast
- BPDU Guard

The focus was on understanding the purpose and operational relevance of these technologies rather than advanced configuration depth.

### Phase 4 — Monitoring and Logs

**Learning objective:** Understand how network devices and services are monitored and how logs support visibility.

Topics:
- Simple Network Management Protocol (SNMP)
- Logs and monitoring
- Syslog
- Network Time Protocol (NTP)

### Phase 5 — Security-Relevant Networking

**Learning objective:** Connect networking fundamentals with cybersecurity and network protection.

Topics:
- Security concepts
- Authentication
- Security technologies
- Device security
- Security rules
- Security fundamentals
- Port security
- DHCP snooping
- Dynamic ARP Inspection
- Secure Shell (SSH)

### Phase 6 — Modern Networking

**Learning objective:** Develop introductory awareness of modern networking technologies and their purpose.

Topics:
- Virtualisation and cloud
- Containers
- Wireless fundamentals
- Wireless security
- Software-Defined Networking (SDN)
- REST APIs
- JSON, XML and YAML

This phase was intended for conceptual understanding rather than mastery.

## Security and Investigation Relevance

Networking knowledge provides the foundation for understanding:

- Network traffic and communication patterns
- IP addresses, ports and protocols
- DNS and DHCP activity
- Network monitoring and logging
- Authentication and network security controls
- Suspicious network behaviour
- Network evidence during security investigations

These foundations support subsequent learning in SOC operations, incident response, threat investigation and digital forensics.
